# Practical Plugin · 实用桌面工具

用于整理可在本地运行的桌面应用与实用小工具。

## 应用列表

| 应用 | 功能 | 适配环境 |
| --- | --- | --- |
| [Eye Rest · 护眼休息](APP/eye-rest/README.md) | 整点全屏休息一分钟，支持桌面浮窗、自定义图片和登录自启动 | Ubuntu 24.04 / GNOME / X11 |

## 快速开始

```sh
git clone https://github.com/YuZekang-dot/Practical-plugin.git
cd Practical-plugin/APP/eye-rest
./install.sh
```

依赖安装、操作方法和卸载步骤请参阅 [Eye Rest 文档](APP/eye-rest/README.md)。

完整应用目录见 [APP 总览](APP/README.md)。
